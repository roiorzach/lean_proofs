# Lean proofs of economic theory manuscripts

This repository contains Lean 4 formalizations of manuscripts by Roi Orzach and coauthors. The proofs were written entirely by an LLM and are machine-checked by Lean's kernel, so their validity does not depend on trusting the LLM. The READMEs were drafted with LLM assistance and reviewed and edited by me.

I did this in part to make the results reproducible and to check that they are correct. Each paper has its own folder, with a README that describes what was verified and how to rebuild it.

The prompt I use to generate these proofs is [here](My%20prompt%20for%20Lean%20proof%20of%20economic%20theory%20papers.md).
